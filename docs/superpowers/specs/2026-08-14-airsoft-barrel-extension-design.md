# 14mm逆ねじバレルエクステンション設計

## 目的

エアソフトガンの14mm逆ねじ（M14×1左ねじ）に取り付け、後段のマズルアクセサリー取り付け位置を15mm前方へ移すアダプターを作る。

## 対象範囲

- OpenSCADで編集・出力できる単一パーツのモデルを追加する。
- 外部OpenSCADライブラリには依存しない。
- ねじの嵌合確認用に、短いオス・メスのテストゲージを同じソースから選択出力できるようにする。
- 実銃や圧力を受ける用途は対象外とする。

## 寸法

| 項目 | 寸法 |
| --- | ---: |
| ねじ規格 | M14×1左ねじ |
| 有効延長 | 15mm |
| 本体外径 | 19mm |
| 中心貫通穴 | 直径10mm |
| メスねじ深さ | 10mm |
| オスねじ長さ | 10mm |
| パーツ全長 | 25mm |
| ねじクリアランス初期値 | 0.25mm |

有効延長は、取り付け元のねじ座面からアダプター前端のねじ座面までの距離とする。パーツ全長は15mmの本体と、前方へ突出する10mmのオスねじから成る。

## 形状

- 後端に深さ10mmのメスねじを設ける。
- 前端に長さ10mmのオスねじを設ける。
- 中心に直径10mmの貫通穴を設ける。
- メスねじ入口とオスねじ先端に面取りを設け、ねじ込み開始時の引っ掛かりを減らす。
- 直径19mmの本体外周には浅い縦溝を等間隔で設け、工具を使わず手締めしやすくする。
- ねじ山は60度の三角形を基本とし、FDMで欠けやすい山頂と谷底はわずかに切り落とす。
- 左ねじであることが形状とパラメーター名から明確に分かる構成にする。

## パラメーター

少なくとも次の値をOpenSCADファイル冒頭で変更可能にする。

- 出力モード: 本体、オスゲージ、メスゲージ
- 有効延長
- 本体外径
- 貫通穴径
- ねじピッチ
- オスねじ長さ
- メスねじ深さ
- ねじクリアランス
- 面取り量
- 外周溝の数と深さ
- 曲面の分割数

寸法の整合性を崩す値に対しては、OpenSCADの`assert()`で分かりやすいエラーを出す。

## 造形条件

- 方式: FDM
- ノズル径: 0.4mm
- 材料: PLA
- 推奨レイヤー高さ: 0.16mmまたは0.2mm
- 推奨壁数: 4周以上
- 推奨インフィル: 40%以上
- 造形方向: 軸を垂直にし、メス側をビルドプレートへ向ける
- サポート: 原則不要

PLA製ねじは横方向の衝撃や過度な締め付けに弱いため、手締めのみを前提とする。高温になる場所や、発射体・燃焼ガス・高圧を受ける用途には使用しない。

## 嵌合調整

FDMプリンターごとの差を吸収するため、最初にテストゲージを造形する。初期クリアランスは0.25mmとし、きつい場合は0.05mmずつ増やし、緩い場合は0.05mmずつ減らす。調整後の値を本体出力にも共通で使用する。

## 検証

### モデル検証

- OpenSCADで警告や非多様体エラーなくレンダリングできる。
- 本体、オスゲージ、メスゲージの各モードをSTLへ出力できる。
- 計算上の外径、全長、貫通穴径、有効延長が設計値と一致する。
- ねじの進行方向が左ねじになっている。
- 最小肉厚が0.4mmノズルの複数押し出し線を確保する。

### 実物検証

- テストゲージがM14×1左ねじの対象物へ手で最後までねじ込める。
- 本体を取り付けた状態で座面間距離が15mmになる。
- 直径10mmの貫通穴に造形崩れや糸引きによる突出がない。
- 通常の手締めで割れ、ねじ山の欠け、著しいがたつきが生じない。

## 成果物

- `airsoft_barrel_extension.scad`: パラメトリックな本体とテストゲージ
- `README.md`: 寸法、出力方法、造形条件、調整方法、安全上の制約

STLはプリンターごとに最適クリアランスが異なるため、初期実装ではリポジトリへ追加せず、調整後にOpenSCADから生成する。
