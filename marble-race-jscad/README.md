# ビー玉の3コース比較実験

サイクロイド・直線・円弧を、同じ出発位置と到着位置で比較するJSCADモデルです。直径16 mmのビー玉を想定した試作設計で、印刷・実走は未確認です。

![モデルとビー玉中心の軌道](output/preview.svg)

## 寸法と部品

単位はmm。Flashforge Adventurer 4の造形範囲220 × 200 × 250 mm以内です。

| STL | 用途 | 外形 X × Y × Z |
| --- | --- | --- |
| `output/cycloid.stl` | サイクロイド | 196 × 26 × 130 |
| `output/straight.stl` | 直線 | 196 × 26 × 123.251 |
| `output/circle.stl` | 円弧 | 196 × 26 × 126.614 |
| `output/gate.stl` | 共通スタート板・平置きで印刷 | 92 × 30 × 2 |

溝は平らな走行面を持つ内幅20 mmのU字断面、側壁厚は3 mm。ビー玉が左右の壁に触れずに進む設計です。コース間の隙間を4 mmにして並べると、全体は196 × 86 × 130 mmになります。ゲートは別印刷です。

## 作成と表示

```sh
mise exec -- npm ci
mise exec -- npm run build
```

このディレクトリで実行するとSTL、寸法JSON、プレビューSVGを`output/`に出力します。`race.js`はJSCADのWeb UIでも開けます。`Part`で3本の表示と各印刷部品を選べます。`assembly`にスタート板は表示していません。

ビルドは形状の閉鎖性、連結性、造形範囲、共通端点、スタート板用溝と走行面の間隔を検査します。独立したtrimesh検査でも、出力した4個のSTLの閉鎖性と面の向きを確認しました。実際の転がり方や保持力を保証する検査ではありません。

## 印刷と設置

最初は直線コース1本とスタート板を印刷して、ビー玉の寸法と板の抜き差しを確認してください。16 mm以外のビー玉では中心軌道の補正が合いません。モデル全体の拡大縮小で調整せず、寸法に合わせた再設計が必要です。

印刷条件の出発点はPLA、0.4 mmノズル、積層0.16 mm、外周3〜4周、上下面5〜6層、インフィル10〜15%です。温度はフィラメントの推奨値を使ってください。STLの平底を下にし、100%スケールで印刷します。下側を埋めた形状なのでサポート不要を想定していますが、スライサーで確認してください。必要なら5 mm程度のブリムを追加できます。

3本の後端を揃え、4 mm間隔で水平な板に並べて両面テープなどで固定します。後端から24 mm付近の切り欠きに、共通スタート板を3本にまたがって縦向きに差し込みます。板の長辺92 mmがコースを横断する方向、30 mmが上下方向です。板の下端は台面から102 mmの位置で支えられ、板の出発側の面に3個のビー玉を当てます。ゲートの遊びがあるため、板を同じ側に軽く寄せてセットします。

左右で傾かないようスタート板を真上に20 mm以上素早く引き抜きます。板が球を持ち上げる、引っ掛かる、3個が揃って静止しない場合は、比較実験の前に調整が必要です。まず大人が1球ずつ確認してください。

終点後の受け皿には薄いスポンジやフェルトを貼ります。球が当たる前の通過時刻を比較するので、緩衝材は終点より先だけに置きます。受け皿からの跳ね返りは未検証のため、器具全体を大きなトレーに置いて試してください。幼い子どもの誤飲を防ぐため、ビー玉は大人が管理してください。

## 実験で比較する位置

ビー玉の**中心**が、開始位置`x = 16, z = 110`から終了位置`x = 157.372, z = 20`まで進みます。水平距離141.372 mm、落差90 mmです。側壁上端の小さな切り欠きが終了位置です。受け皿への衝突音は比較基準にしません。

スマートフォンのスロー動画で、中心が終点の真上を通過するフレームを比べます。サイクロイドと円弧の差は小さいので、まず直線と曲線の違いを見てから、曲線同士を比べるのがよさそうです。同じ直径・材質の球を使い、球をコース間で入れ替え、数回繰り返してください。

## 曲線と実験の限界

サイクロイドの中心軌道は、`a = 45`、`0 ≤ θ ≤ π`として次の式です。

```text
x = 16 + a(θ − sin θ)
z = 110 − a(1 − cos θ)
```

円弧は同じ端点を通り、終点で水平になる円の一部です。半径は`(水平距離² + 落差²) / (2 × 落差)`、約156.033 mmです。直線は同じ端点を結びます。各軌道の上向き法線に対して8 mm下側に走行面を置き、球の半径を補正しています。曲線は240区間の折れ線近似です。

最速降下線としてのサイクロイドは理想化された条件の結果です。この器具には積層の凹凸、球の回転、滑り、壁への接触、ゲートの解放誤差があります。特にサイクロイドの開始接線は鉛直で、開始直後に純粋な転がりを保つことは期待できません。「必ずサイクロイドが勝つ」と決めずに、予想と観察の違いも調べる教材として使います。このサイズでは厳密な最速降下線の実証までは狙っていません。
