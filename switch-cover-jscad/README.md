# 円形スイッチキャップの写真ベース試作

黄色い枠のスイッチで紛失したキャップを、隣接する赤いキャップの写真から再構成したモデルです。寸法は mm。実機への取付・押下・復帰は未検証です。

参照写真は `/Users/asonas/Downloads/IMG_6261.jpeg`、`IMG_6263.jpeg`、`IMG_6265.jpeg`、`IMG_6266.jpeg`、`IMG_6267.jpeg`、`IMG_6268.jpeg` です。写真ファイルはリポジトリへ複製していません。

追加写真から、中空の円形キャップ、向かい合う2本の外向き留め爪、側面の切り欠き、十字方向の補強リブと中央の細い突起を確認しました。`/Users/asonas/Downloads/IMG_6269.jpeg` と依頼者の訂正に基づき、中央の差し込み爪は2本です。依頼者が測定した2 × 4 mmはスイッチ側の受け穴の内寸として扱います。

## 採用寸法

| 部位 | モデル値 | 根拠・確度 |
| --- | ---: | --- |
| 本体外径 | 25 mm | 依頼者申告。追加写真の約25 mmとも整合 |
| 爪先までの全高 | 16 mm | 側面写真の定規から約16 mmと推定。遠近差あり |
| 外周壁の高さ | 10.5 mm | 側面写真から約10〜11 mmと推定 |
| 押面板厚 | 1.8 mm | 造形用の設計値。実測値ではない |
| 外周壁厚 | 1.2 mm | 写真の概形に基づく設計値 |
| 爪の幅／外側への張り出し | 3.0 / 0.7 mm | 写真からの仮値。嵌合確認が必要 |
| 中央突起の先端高さ | 押面から6.5 mm | 仮値。押しっぱなしや空振りの有無を実機で確認 |
| スイッチ側の受け穴内寸 | 2 × 4 mm | 依頼者の実測値 |
| 中央の2本の爪の全体外寸 | 1.6 × 3.6 mm | 受け穴に対して片側0.2 mmの隙間を設けた設計値 |
| 中央の爪1本の断面／爪間の隙間 | 0.8 × 1.6 mm / 2.0 mm | 設計値。爪の厚さと隙間は実測未確認 |
| 2か所の切り欠き幅 | 12 / 5 mm | 撮影方向による幅の違いを暫定再現。未確定 |

押面は造形しやすい平面と0.5 mmの縁の面取りで構成しています。赤い実物のわずかな丸みは厳密には再現していません。写真では0.1 mm単位の嵌合寸法を確定できないため、これらの値は `cover.js` 冒頭と切り欠き定義で調整します。

## ファイルと生成

- `cover.js`: 寸法と形状。Manifoldで立体演算を行い、JSCAD形状へ変換
- `build.js`: 閉じた形状・外寸・体積を検証しSTLを出力
- `output/switch-cover-v2-photo-prototype.stl`: 修正版の試作STL
- `output/preview.png`: 裏面と押面の比較図
- `output/validation.json`: 出力STLをTrimeshで独立検証した結果

```sh
mise exec -- npm ci
mise exec -- npm run build
```

STLは押面を下、爪を上にした向きで、押面が Z=0 にあります。単位は mm、スライサーの倍率は100%です。形状検証は閉じた1個の立体・面の向き・外寸を対象とし、爪の強度や実機嵌合を保証するものではありません。

## 製品の照合状況

三和電子の[OBSF-30公式情報](https://sanwa-d.co.jp/product/button/obsf-30.html)と[同社カタログ](https://rs2006.co.jp/e/sanwaseimitsu/Sanwa2020OCR.pdf)では、取付穴30 mm・押面25 mm・SW-68の組合せが確認できます。25 mmの押面からは30 mm級アーケードボタンが候補になります。ただし写真の白い可動部・刻印からメーカーや型式までは特定できていません。モデルは市販品の互換仕様を保証せず、実物写真に基づく試作品として扱います。

## Polycamを追加資料にする場合

[公式の小物撮影手順](https://learn.poly.cam/hc/en-us/articles/37064519912724-Scanning-Small-Objects-in-Object-Mode)に沿ってObject Modeの写真測量を使い、裏側と爪を複数方向から撮ります。[GLBをBlenderへ取り込む手順](https://learn.poly.cam/hc/en-us/articles/42497420365716-How-to-Optimize-Your-Captures-in-Blender)も公開されています。

既知寸法で全体の縮尺を合わせても、爪や溝の欠落・局所的な変形は補正できません。スキャンは形状比較に用い、嵌合寸法は実測または試着で確定します。
